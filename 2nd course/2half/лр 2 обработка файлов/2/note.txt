BMP 24бит: пиксель в 3байта(bgr - ИМЕННО ТАКОЙ ПОРЯДОК), палитры нет, без сжатия
3 части:
1) Заголовок файла (BITMAPFILEHEADER) - 14байт. Общая информация о файле.
    bfType (2 байта) — сигнатура "BM".
    bfOffBits (4 байта) — смещение до начала пиксельных данных. Оно говорит, с какого байта начинаются сами пиксели.(10-13байты)
2) Заголовок изображения (BITMAPINFOHEADER) - 40байт. Информация об изображении.
    biWidth (4 байта) — ширина в пикселях.(18-21)
    biHeight (4 байта) — высота в пикселях.(22-25)
    biBitCount (2 байта) — бит на пиксель (для нас должно быть 24)(28байт)
3) Пиксельные данные - Переменный размер. Само изображение.	Хранятся в виде последовательности байт BGR.

Каждая строка пикселей в BMP должна быть кратна 4 байтам. Если строка не кратна 4, в конце добавляются "пустые" байты (padding).
Формула для расчета:
bytewidth = ((width * 3) + 3) & ~3;
примеры:
Ширина = 1 пиксель: 1 * 3 = 3 байта. До кратности 4 не хватает 1 байта. bytewidth = 4.
Ширина = 2 пикселя: 2 * 3 = 6 байт. До кратности 4 не хватает 2 байт. bytewidth = 8.
Данные пикселей хранятся снизу вверх (первая строка в файле — нижняя)

КОД:
формат r+b - чтение и запись в бин режиме

fread(signature, 1, 2, f); - 1-что записывать, 2-размер одного эл в байтах, 3-сколько эл надо прочесть, 4-откуда читается
fwrite(color, 1, 3, f); - 1-что записать,2-размер одного эл в байтах, 3-сколько эл надо прочесть, 4-куда записать
перемещение указателя текущ позиции в файле: fseek(f, 10, SEEK_SET); - 1-внутри чего перемещаться, 2-кол-во байт на которое надо переместится, откуда считывать смещение(SEEK_SET - отсчет идет от начала файла.)

// 5. Расчет ширины строки с учетом выравнивания
    long width_row = (width * 3 + 3) - (width * 3 + 3)%4;
    printf("ширина строки в байтах: %ld\n", width_row);
    
    unsigned char color[3] = {0, 0, 0}; 
    
    // Переменная для хранения текущей позиции в файле
    long pos;

    // Идем по строкам (i - номер строки снизу)
    for (int i = 0; i < height; i++) {
        // Вычисляем позицию для левого пикселя в i-й строке снизу
        // i * bytewidth - смещение до начала i-й строки
        // i * 3 - смещение до i-го пикселя в строке (для левой диагонали)
        pos = smeshenie + i * width_row + i * 3;
        fseek(f, pos, SEEK_SET);
        fwrite(color, 1, 3, f);

        // Вычисляем позицию для правого пикселя в i-й строке снизу
        // (height - i - 1) * 3 - смещение для правой диагонали
        pos = smeshenie + i * width_row + (height - i - 1) * 3;
        fseek(f, pos, SEEK_SET);
        fwrite(color, 1, 3, f);
    }
width * 3 — это количество байт, нужное для хранения одной строки пикселей без учёта выравнивания
+ 3 — мы прибавляем 3, чтобы при делении на 4 получить остаток, который «дотягивает» до следующего кратного.
% 4 — остаток от деления на 4. Если исходное число уже кратно 4, остаток будет 0.
Затем мы вычитаем этот остаток из увеличенного числа. В результате получается число, которое делится на 4 нацело.
