### 🛠 ШПАРГАЛКА: Копирование файловой структуры (День 2)

#### 1. Создание каталогов и настройка прав
Когда мы нашли папку, мы должны создать такую же папку в месте назначения и выставить ей такие же права.

**`mkdir(путь, права)`**
*   **Как использовать:** `mkdir("/путь/к/новой/папке", st.st_mode & 07777);`
*   **Аргументы:** 
    *   `путь` (строка) — куда создаем.
    *   `права` (число в 8-ричной системе, `mode_t`) — права доступа.
*   **⚠️ Проблемы:** 
    *   Система может обрезать права из-за `umask` (системные настройки безопасности). Поэтому **сразу после `mkdir` всегда вызывай `chmod`**.
    *   Ошибка, если родительская папка не существует.

**`chmod(путь, права)`**
*   **Как использовать:** `chmod("/путь/к/новой/папке", st.st_mode & 07777);`
*   **Аргументы:** 
    *   `путь` (строка).
    *   `права` (число).
*   **⚠️ Проблемы:** 
    *   **Забить маску `& 07777`!** В `st.st_mode` зашиты не только права (`rwx`), но и тип файла (что это папка). Если передать `st.st_mode` без `& 07777`, права сломаются. Маска `07777` отрезает тип файла и оставляет только права.

#### 2. Работа с символическими ссылками (Symlinks)
Ссылку нельзя просто «скопировать» как файл. Нужно узнать, куда она смотрит, и создать новую ссылку, смотрящую туда же.

**`readlink(путь_ссылки, буфер, размер_буфера)`**
*   **Как использовать:** 
    ```c
    char target[PATH_MAX];
    int len = readlink("my_link", target, sizeof(target) - 1);
    target[len] = '\0'; // ОБЯЗАТЕЛЬНО!
    ```
*   **Аргументы:**
    *   `путь_ссылки` (строка) — откуда читаем.
    *   `буфер` (массив `char`) — куда положим результат.
    *   `размер` (число) — размер буфера.
*   **⚠️ Проблемы:** 
    *   **Главная ловушка:** `readlink` **НЕ** добавляет символ конца строки `\0` в конец! Если ты не напишешь `target[len] = '\0';`, в буфере будет мусор, и ссылка создастся в никуда.
    *   Возвращает `-1`, если это не ссылка или нет прав.

**`symlink(цель, имя_новой_ссылки)`**
*   **Как использовать:** `symlink(target, "/копия/my_link");`
*   **Аргументы:**
    *   `цель` (строка) — **КУДА** смотрит ссылка (то, что мы прочитали через `readlink`).
    *   `имя_новой_ссылки` (строка) — **КАК** называется новая ссылка.
*   **⚠️ Проблемы:** 
    *   **Порядок аргументов!** Он нелогичный. Сначала идет *цель* (куда смотрим), потом *имя создаваемой ссылки*. Студенты постоянно их путают местами.
    *   Ошибка, если файл с таким именем уже существует.

#### 3. Создание пустых регулярных файлов
Если это не папка и не ссылка, а «другой тип» (или обычный файл), мы просто создаем пустой файл с таким же именем.

**`fopen(путь, режим)` и `fclose(файл)`**
*   **Как использовать:** 
    ```c
    FILE *f = fopen("/копия/file.txt", "w");
    if (f != NULL) fclose(f);
    ```
*   **Аргументы:**
    *   `путь` (строка).
    *   `режим` (строка): `"w"` (write) — создает файл или очищает его, если он есть.
*   **⚠️ Проблемы:** 
    *   Забыть проверить `f == NULL` (например, нет прав на запись).
    *   Забыть вызвать `fclose(f)`. Файл останется «открытым» для системы.
    *   *Не забудь потом вызвать `chmod` для этого файла, чтобы выдать ему права из `st.st_mode & 07777`!*

#### 4. Склейка путей (Клей для всего кода)
Тебе постоянно придется строить новые пути.

**`snprintf(буфер, размер, формат, ...)`**
*   **Как использовать:** `snprintf(fullpath, sizeof(fullpath), "%s/%s", src_dir, entry->d_name);`
*   **Аргументы:**
    *   `буфер` — куда пишем результат.
    *   `размер` — `sizeof(буфер)`, чтобы не вылезти за пределы памяти.
    *   `формат` — `"%s/%s"` (склеить две строки через слэш).
*   **⚠️ Проблемы:** 
    *   Забыть слэш `/` в формате. Получится `папкафайл` вместо `папка/файл`.
    *   Передать размер больше, чем реальный размер массива (переполнение буфера). Всегда используй `sizeof()`.

### 🔄 КРАТКОЕ ПОВТОРЕНИЕ (День 1)

**`opendir(путь)`** -> Открывает папку. Возвращает `DIR *`. (Проблема: возвращает `NULL`, если папки нет).
**`readdir(поток)`** -> Читает следующий файл. Возвращает `struct dirent *`. (Проблема: возвращает `.` и `..`, их надо пропускать через `strcmp`).
**`lstat(путь, &st)`** -> Получает «паспорт» файла в структуру `st`. (Проблема: если использовать `stat` вместо `lstat`, он «пройдет» по ссылке и сломает логику копирования ссылок).

```c
    // Прочитали ссылку (readlink)
    // Создали новую ссылку (symlink)
} 
else {
    // Создали пустой файл (fopen + fclose)
    // Выдали права (chmod)
}
```
