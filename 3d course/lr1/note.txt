Сначала — как это устроено идейно
В Linux каждый пользователь имеет:

UID — числовой идентификатор пользователя
GID — числовой идентификатор основной группы
Плюс может входить в дополнительные группы

Группы нужны для управления доступом к файлам и ресурсам. Например, группа audio даёт доступ к звуковым устройствам, группа sudo — права администратора.
Где хранится эта информация?
В двух файлах:

/etc/passwd — список пользователей (имя, UID, GID, домашняя папка и т.д.)
/etc/group — список групп и их членов

Посмотри на них прямо сейчас в терминале:
bashcat /etc/passwd | head -5
cat /etc/group | head -5
```

Формат `/etc/passwd`:
```
username:password:UID:GID:info:home:shell
```

Формат `/etc/group`:
```
groupname:password:GID:member1,member2,member3
Важный нюанс: пользователь входит в группу двумя способами:

Его основной GID в /etc/passwd совпадает с GID группы
Его имя упомянуто в списке членов группы в /etc/group

Для работы с этими данными в C есть специальные системные вызовы — не нужно парсить файлы вручную.

День 1: Читаем данные о пользователе
Ключевые функции
В C для работы с пользователями и группами используют функции из <pwd.h> и <grp.h>.
getpwnam(name) — получить запись о пользователе по имени
Возвращает указатель на структуру passwd:
cstruct passwd {
    char  *pw_name;   // имя пользователя
    uid_t  pw_uid;    // UID
    gid_t  pw_gid;    // основной GID
    char  *pw_dir;    // домашняя директория
    // и другие поля
};
getgroups / getgrouplist — получить список групп пользователя
getgrent() — итерация по всем группам в системе
Задание на День 1
Напиши и запусти эту программу. Она читает данные о пользователе и выводит его группы:
#include <stdio.h>
#include <stdlib.h>
#include <pwd.h>
#include <grp.h>

int main(int argc, char *argv[]) {
    if (argc != 2) {
        printf("Использование: %s <имя_пользователя>\\n", argv[0]);
        return 1;
    }

    const char *username = argv[1];

    // Получаем запись о пользователе
    struct passwd *pw = getpwnam(username);
    if (pw == NULL) {
        printf("Пользователь '%s' не найден\\n", username);
        return 1;
    }

    printf("Пользователь: %s\\n", pw->pw_name);
    printf("UID: %d\\n", pw->pw_uid);
    printf("Основной GID: %d\\n", pw->pw_gid);

    // Узнаём сколько групп у пользователя
    int ngroups = 0;
    // Первый вызов с ngroups=0 вернёт -1, но запишет реальное количество в ngroups
    getgrouplist(username, pw->pw_gid, NULL, &ngroups);

    printf("Количество групп: %d\\n", ngroups);

    // Выделяем память под массив GID
    gid_t *groups = malloc(ngroups * sizeof(gid_t));

    // Второй вызов — реально заполняет массив
    getgrouplist(username, pw->pw_gid, groups, &ngroups);

    // Выводим имя каждой группы
    printf("Группы:\\n");
    for (int i = 0; i < ngroups; i++) {
        struct group *gr = getgrgid(groups[i]);
        if (gr != NULL) {
            printf("  - %s (GID: %d)\\n", gr->gr_name, groups[i]);
        }
    }

    free(groups);
    return 0;
}
