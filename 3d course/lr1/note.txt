    stat() — системный вызов, который достает метаданные файла.
    int stat(const char *path, struct stat *buf)
    Заполняет структуру stat информацией о файле.
    Возвращает 0 при успехе, -1 при ошибке.

    Поля struct stat:
    -st_uid — ID владельца
    -st_gid — ID группы
    -st_mode — права доступа и тип файла (битовая маска)

    Как преобразовать ID в имена?
    getpwuid(st_uid) → struct passwd * с полями pw_name
    getgrgid(st_gid) → struct group * с полем gr_name

    Как расшифровать st_mode?
    макросы:
    S_ISREG(st_mode) — обычный файл
    S_ISDIR(st_mode) — каталог
    S_ISFIFO(st_mode) — fifo-канал
    S_ISLNK(st_mode) — символическая ссылка

    Права доступа (9 бит: владелец, группа, остальные; для каждого: чтение, запись, выполнение):
    S_IRUSR, S_IWUSR, S_IXUSR — для владельца
    S_IRGRP, S_IWGRP, S_IXGRP — для группы
    S_IROTH, S_IWOTH, S_IXOTH — для остальных

    Спецправа:
    S_ISUID — SUID
    S_ISGID — SGID
    S_ISVTX — Sticky bit
    
    getpwuid используется для получения информации о пользователе (имя, домашний каталог, UID, GID) по его числовому идентификатору (UID) из базы данных системы (обычно /etc/passwd).
    пример:    //владелец
               struct passwd *pw = getpwuid(st.st_uid);
               printf("хозяин: %s (%d)\n", pw->pw_name, st.st_uid);

    snprintf() - это "безопасная" версия printf(), которая записывает результат не на экран, а в строку (буфер), и ограничивает размер, чтобы не было переполнения.
    почему "%s/%s" - Это шаблон, который создает путь к файлу, вставляя слеш между частями(путь/имя файла): snprintf(fullpath, sizeof(fullpath), "%s/%s", path, filename);
// Результат: "./myfile.txt"
